# MY EXPO BAG — 消費者ページ v1.0.1

**表示バージョンは、プロジェクトの一通りの機能が完成するまで `1.0.1` 固定です。**

## 今回完成した範囲

- 商品一覧 → 商品詳細 → カラー選択 → MY BAG → 購入QR の動線
- 展示会用途に合わせ、商品説明を省略。商品画像（1商品最大2枚）、商品名、カテゴリ、商品ID、価格を中心に表示
- カラーバリエーションは文字とコードで選択し、カラー別画像は不要。購入QRには商品IDと選択カラーコード、数量を記録
- 商品詳細のおすすめ組み合わせ（最大3組）、割引ありなら「◯円お得」、割引なしなら「◯点で合計◯円」
- 名前とメールアドレスを**登録して購入**／**入力をスキップ**の選択
- 事前設定 `event.appPurchaseDiscountPercent` が0を超える場合、**名前・メールを両方登録した購入者だけ**アプリ購入割引。スキップした購入者には適用しない
- メルマガ同意は**別の任意チェックボックス**。割引と広告配信同意は連動しない
- QRの下にはアプリ購入割引前の合計金額、登録割引がある場合のみ赤字で割引率・割引額・割引後金額
- 実際のQRを読めることをテスト済み。スマホ画面での可読性のためデータ形式を簡潔にした

## 価格の計算順

1. 通常価格から展示会限定価格へ（設定がある場合）
2. 対象の組み合わせによるセット割引（存在する場合。数量は重複使用しない）
3. 名前・メールを登録した人だけ、上記合計からアプリ購入割引

円単位に四捨五入。ノベルティ対象の判定には、最終のお支払い予定額を使います。

例えば、ランタン（展示会価格4,200円）＋テーブル（5,900円）にセット割引10%なら合計9,090円です。登録者向けアプリ購入割引10%のとき、登録した人は8,181円、スキップした人は9,090円になります。

## 今回のQRに実際に入る情報

QRの内容は**JSON文字列**で、読み取りやすさを優先した短いキーを使います。

| キー | 内容 |
|---|---|
| `t` | 形式識別子 `MEB2` |
| `o` | ランダムなデモ注文ID |
| `b` | ブランドID |
| `e` | 展示会・イベントID |
| `i` | `[[商品ID, カラーコード, 数量], ...]` |
| `r` | 情報登録あり＝1／スキップ＝0 |
| `c` | `JPY` |
| `s` | アプリ購入割引前の合計（税込） |
| `p` | 適用したアプリ購入割引率（%） |
| `d` | アプリ購入割引額（円） |
| `a` | 最終お支払い予定額（円） |

**名前・メールアドレスはQRに入れません。** `r=1` だけでは本当に登録されたかの証明にはなりません。後日の本番対応ではQRの注文IDをサーバー内の顧客レコードと関連付け、売り手側で注文ID・金額・割引資格・会計・ノベルティ交換を検証します。

現時点では**顧客データのサーバー保管、CSV保存、会計確定、QRの二重使用防止は未実装**です。**実際の決済には使用しないでください。** 登録した氏名・メールは画面を開いている間だけメモリに保持し、QR画像やサーバーに保存しません。

## GitHubへ反映するファイル

今回の更新ZIPには以下の4ファイルがあります。`index.html` / `qr.js` / `sw.js` / `manifest.webmanifest` / `myexpobag_icon.png` は変更していません。

- `app.js` — カラー選択・MY BAG・登録/スキップ・割引条件・QR出力
- `styles.css` — 商品/カラー/購入画面のUI
- `config.js` — カラー登録と10%割引の**テスト用設定**（既存の商品データを上書きしたくない場合は丸ごと上書きしない）
- `README.md` — この仕様とQRデータ形式

これら4ファイルを `index.html` と同じ階層にアップロードして、既存ファイルを上書きしてください。GitHub Pagesへのデプロイが完了すると公開版に反映されます。

**`config.js` に独自の商品・価格・ブランド設定がある場合**は、そのファイルをバックアップし、以下の設定だけを既存データへ追加してください。

```js
// event の中。アプリ登録特典がなければ 0 にする
appPurchaseDiscountPercent: 10,

// products の各商品に。カラー画像は不要
variants: [
  { code: 'BK', name: 'ブラック' },
  { code: 'KH', name: 'カーキ' },
],
// 任意の2枚目（画像登録機能は管理ページ側で開発予定）
image2: '',
```

商品ごとの `variants` は任意で、カラー指定不要な商品は `variants: []` または未設定にしてください。

なお、今回のZIPではテストが分かりやすいよう `appPurchaseDiscountPercent: 10` にしています。本番で割引を無効にする場合は `0` に変更してください。

## テスト結果

- 名前＋メール登録：商品ID・カラーコード・数量と割引前合計9,090円、10%（909円）、最終8,181円がQRに入り、QR画像からJSONを読み出せることを確認
- 入力スキップ：同じ商品でも10%割引が適用されず、9,090円のQRが発行されることを確認
- 割引設定0%：名前を登録してもアプリ購入割引を行わないことを確認
- カラーバリエーションの選択、組み合わせ商品の追加、商品説明の非表示をブラウザ上で確認
